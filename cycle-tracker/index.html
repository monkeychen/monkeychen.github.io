周期资产跟踪系统

铜、金、铝、锂、钾肥、煤、油、船舶。每个月只更新：供给、需求、库存、价格、资本开支、公司盈利。

六因子热力图

所有资产统一用同一套方向定义：改善=对周期资产盈利更有利，恶化=更不利。

执行框架

1. 口径固定

不因行情变化临时更换指标。国际机构发布频率低于月度时，月度沿用最近一次官方值，并用高频代理补充。

2. 方向统一

供给收缩、需求增强、库存去化、价格走强、资本开支克制、盈利改善，统一记为正向。

3. 拐点确认

单月变化只做观察；连续两个月同向，或官方季度数据与高频代理共振，才升级为趋势。

4. 库存优先

供需数据存在滞后时，优先观察库存与价格是否确认。库存去化但价格不涨，通常意味着需求质量需要复核。

5. Capex 反身性

高利润推动资本开支扩张，通常意味着未来供给增加。资本开支作为中期反向指标，不与当期利润简单同向解释。

6. 盈利落地

最终要回到企业：价格上涨是否覆盖成本，单位利润、EBITDA、自由现金流是否真的扩张。

评分规则

六因子等权。每项信号取 +2 / +1 / 0 / -1 / -2，综合转换为 0–100 分。80–100 为强景气，60–79 为偏强，40–59 为中性，20–39 为偏弱，0–19 为弱景气。评分只是提示器，不代替原始数据。
